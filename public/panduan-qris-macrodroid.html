1 Bagaimana Sistem Verifikasi Otomatis Ini Bekerja?

Biasanya, integrasi QRIS otomatis membutuhkan akun agregator payment gateway (seperti Midtrans, Xendit, Tripay) yang memotong biaya admin per transaksi (Rp 750 - Rp 2.500 atau 0.7%) dan pencairan dana H+1.

Dengan sistem QRIS Dinamis + Webhook MacroDroid, uang pembayaran dari pelanggan langsung masuk ke rekening bank / e-wallet Anda detik itu juga tanpa potongan sepeser pun.

01
Pelanggan Cek Tagihan

Tagihan Rp 100.000 otomatis diberi kode unik 3 digit, misal menjadi Rp 100.090.

02
Scan QRIS Dinamis

QRIS mengunci nominal Rp 100.090 (Tag EMVCo 54). Pelanggan tinggal klik konfirmasi bayar di m-Banking.

03
Notifikasi HP Masuk

DANA/BCA mengirim notifikasi: "Berhasil menerima uang Rp 100.090" ke HP Admin.

04
MacroDroid -> Webhook

MacroDroid menangkap teks notifikasi & menembakkan HTTP POST ke server billing ISP secara instan.

05
Lunas & Kirim PDF

Billing mencocokkan nominal, tagihan otomatis PAID, un-isolir Mikrotik, dan kirim Struk PDF via WA.

Mengapa Perlu Kode Unik 3 Digit (1 - 999)?
Jika ada 2 pelanggan yang sama-sama berlangganan paket 100rb dan membayar di jam yang sama, kode unik (misal: Pelanggan A bayar 100.045 dan Pelanggan B bayar 100.120) membuat server tahu dengan 100% presisi siapa yang baru saja membayar!

2 Cara Mengganti / Upload QRIS Anda Sendiri

Jika di sistem Anda masih terpasang QRIS bawaan / milik orang lain, Anda dapat menggantinya dengan QRIS toko / ISP Anda sendiri hanya dalam beberapa detik.

Langkah 1: Siapkan File Gambar QRIS Anda
  • Bisa menggunakan QRIS dari DANA Bisnis, BCA Merchant, QRIS Mandiri Livin Usaha, Nobu, GoPay Merchant, atau Bank apapun.
  • Pastikan foto/screenshot QRIS memiliki resolusi bersih, tidak terpotong, dan tidak buram. Format yang didukung: .jpg, .png, atau .webp.
Langkah 2: Upload di Menu Pengaturan Billing
  1. Buka browser dan login ke Admin Portal: /admin/settings#payment.
  2. Gulir ke kartu "QRIS Statis & Dinamis (Semi-Otomatis)".
  3. Pada bagian Upload File Gambar QRIS, klik tombol Choose File / Pilih File dan pilih gambar QRIS Anda.
  4. Klik tombol biru Upload.
Ekstraksi String EMVCo Otomatis:
Saat Anda mengklik Upload, mesin decoder di sistem akan memindai barcode QRIS secara otomatis dan mengisi kolom QRIS Static Payload (string berawalan 000201...). Anda tidak perlu mengetik payload manual!
Langkah 3: Periksa dengan Fitur "Preview QRIS"

Setelah halaman me-refresh, thumbnail QRIS akan muncul di sebelah kanan form upload.

  • Klik pada gambar thumbnail QRIS tersebut untuk membuka jendela popup / preview ukuran penuh.
  • Sistem akan otomatis mengekstrak dan menampilkan Nama Merchant (Tag 59) dan Kota (Tag 60).
  • Pastikan Nama Merchant yang tertera sudah sesuai dengan nama usaha atau nama e-wallet Anda.
  • Klik Simpan Pengaturan di bawah halaman untuk memastikan seluruh konfigurasi tersimpan ke database.

3 Panduan Setup Aplikasi MacroDroid di Smartphone

MacroDroid adalah aplikasi otomatisasi Android yang bertugas membaca notifikasi uang masuk dari aplikasi bank/e-wallet Anda dan mengirimkannya ke webhook Billing ISP.

Penting: Pengaturan Izin di HP Android
1. Buka Pengaturan HP > Aplikasi > MacroDroid.
2. Aktifkan Izin Akses Notifikasi (Notification Access).
3. Matikan Penghemat Baterai (Battery Optimization > Pilih "Don't Optimize" / "Unrestricted").
4. (Untuk Xiaomi/Oppo/Vivo/Realme): Aktifkan Auto-start dan kunci aplikasi MacroDroid di recent apps agar tidak ditutup oleh sistem Android saat layar mati.
Langkah-Langkah Membuat Macro Baru:
A. Konfigurasi Trigger (Pemicu Notifikasi)
  1. Buka aplikasi MacroDroid > Tap Add Macro.
  2. Pada bagian Triggers (kotak merah), tap tombol + (Tambah).
  3. Pilih kategori: Device Events > Notification > Notification Received.
  4. Pilih opsi Select Applications > Klik OK > Centang aplikasi e-wallet Anda (Contoh: DANA, BCA mobile, Livin' by Mandiri, dll).
  5. Pada kolom Text Content, pilih Any Content (atau masukkan kata kunci seperti menerima uang jika hanya ingin menangkap notif saldo masuk).
  6. Tap OK untuk menyimpan Trigger.
B. Konfigurasi Action (Pengiriman HTTP POST Webhook)
  1. Pada bagian Actions (kotak biru), tap tombol + (Tambah).
  2. Pilih kategori: Connectivity > HTTP Request.
  3. Atur parameter HTTP Request sebagai berikut:
    • Request Method: Pilih POST
    • URL: Masukkan URL Webhook dari tab Pengaturan Billing Anda:
FORMAT URL WEBHOOK 
https://domain-billing-anda.com/api/webhook/v1/payment-notif?secret_key=YOUR_WEBHOOK_SECRET
  1. Content Type: Pilih application/json
  2. Request Body (Raw Text): Salin dan tempel JSON payload di bawah ini persis apa adanya:
BODY JSON MACRODROID (Gunakan variabel bawaan MacroDroid) 
{
  "service": "[not_app_name]",
  "title": "[not_title]",
  "content": "[not_body]",
  "time": "[not_time]"
}

Catatan: Kode [not_app_name], [not_title], dan [not_body] adalah Magic Text MacroDroid yang otomatis diisi dengan nama aplikasi dan teks notifikasi saldo masuk.

C. Simpan & Aktifkan Macro

Beri nama Macro Anda (misal: "Webhook Pembayaran DANA ISP"), lalu klik tombol Centang/Simpan di pojok kanan bawah. Pastikan toggle utama di halaman depan MacroDroid dalam status ON (Aktif).

4 Fitur Kirim Otomatis Invoice PDF via WhatsApp

Selain notifikasi teks biasa, sistem billing ini memiliki generator dokumen PDF resmi yang dilengkapi nomor invoice, nama pelanggan, detail paket internet, rincian nominal, tanggal bayar, dan cap stempel LUNAS.

Cara Mengaktifkan:
  1. Buka Pengaturan > Tab Pembayaran & QRIS.
  2. Lihat pada opsi: "Kirim File Dokumen PDF Saat Pembayaran Lunas".
  3. Pilih opsi: "✅ Aktif (Otomatis generate & kirim file Invoice.pdf ke WhatsApp pelanggan)".
  4. Klik tombol Simpan Pengaturan di bawah.
Bagaimana Pelanggan Menerimanya?
Begitu notifikasi MacroDroid masuk dan nominal cocok, WhatsApp Gateway (Baileys / Fonnte) akan otomatis mengirimkan pesan konfirmasi beserta lampiran file Invoice-INVxxxx.pdf langsung ke nomor WhatsApp pelanggan dalam hitungan 2-5 detik!

5 Simulasi Testing & Membaca Log Webhook

Sebelum digunakan pelanggan secara massal, Anda bisa melakukan uji coba sendiri untuk memastikan webhook server merespons dengan benar.

A. Cara Melihat Log Transaksi Masuk:

Di halaman Pengaturan > Tab Pembayaran & QRIS, gulir ke bagian paling bawah ke tabel "Log Notifikasi Webhook E-Wallet".

  • Setiap request dari MacroDroid akan dicatat di tabel ini lengkap dengan jam, nama aplikasi, teks mentah, nominal yang berhasil diekstrak, dan status pencocokan (MATCHED / UNMATCHED).
  • Jika status MATCHED berwarna hijau, berarti tagihan pelanggan berhasil dilunasi otomatis!
B. Simulasi Pengujian Manual Menggunakan cURL:

Anda dapat membuka Terminal / Command Prompt di komputer Anda dan menjalankan perintah cURL berikut (ganti nominal sesuai tagihan yang sedang pending di billing Anda):

COMMAND TESTING CURL 
curl -X POST "https://domain-anda.com/api/webhook/v1/payment-notif" \
  -H "Content-Type: application/json" \
  -H "x-webhook-secret: YOUR_WEBHOOK_SECRET" \
  -d '{
    "service": "DANA",
    "content": "Berhasil menerima uang Rp 100.090 dari Pelanggan Uji Coba",
    "app": "id.dana"
  }'

6 Tanya Jawab (FAQ) & Tips Keamanan

Jika pelanggan membayar via scan QRIS dinamis di layar, nominal sudah otomatis terkunci bersama kode unik sehingga mustahil salah ketik nominal. Jika pelanggan mentransfer manual via bank tanpa kode unik, pembayaran akan tetap tercatat di log webhook sebagai UNMATCHED (belum cocok). Admin cukup membuka menu Billing > Pelanggan dan mengklik tombol "Tandai Lunas" manual.

Sangat aman. Sistem webhook billing ISP sudah dilengkapi proteksi ketat:
  • Semua pesan dari aplikasi pesan instan (WhatsApp, Telegram, SMS pribadi) otomatis diblokir/diabaikan oleh sistem untuk mencegah pelanggan memanipulasi kata-kata.
  • Request hanya diproses jika secret_key cocok dengan yang ada di server Anda.
  • Sistem hanya membaca notifikasi resmi dari package name aplikasi perbankan terpercaya.

Sebaiknya gunakan 1 unit smartphone Android khusus di kantor (misal HP operasional kantor yang standby di-charge) yang terkoneksi Wi-Fi 24 jam. Jika HP sempat mati, saat HP dinyalakan kembali, riwayat mutasi di aplikasi e-wallet tetap aman dan admin bisa melakukan verifikasi manual jika ada tagihan yang belum ter-trigger.
