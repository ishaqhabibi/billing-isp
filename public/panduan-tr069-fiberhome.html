Metode 1: Zero-Touch via OMCI Profile di OLT (Recommended!)

Solusi Terbaik Untuk 100+ Modem

Dengan metode ini, Anda sama sekali tidak perlu mencolok kabel LAN ke laptop atau membuka web GUI modem satu per satu. Cukup buat profil WAN di OLT. Setiap kali modem Fiberhome D2 atau F3 dicolokkan ke kabel optik dan di-bind ke profil ini, OLT akan otomatis menyuntikkan (push) konfigurasi TR-069 dan PPPoE ke modem!

1
Buka OLT Web GUI / Telnet (IP: 172.16.0.2)

Akses OLT Bionfiber dari jaringan manajemen (VLAN 10). Buka menu ONU Profile → WAN Service Profile.

2
Buat WAN Service Profile untuk TR-069 (VLAN 20)
WAN 1 (Management / TR-069):
- Service Name     : WAN_TR069
- Service Type     : TR069 (atau Management)
- Mode             : Route
- IP Mode          : DHCP (IPv4)
- VLAN Mode        : Tag
- VLAN ID          : 20
- 802.1p Priority  : 0
- Port Binding     : JANGAN CENTANG APAPUN (khusus internal CPU modem)
- NAT              : Enabled
3
Buat WAN Service Profile untuk PPPoE (VLAN 100)
WAN 2 (Internet PPPoE):
- Service Name     : WAN_INTERNET
- Service Type     : INTERNET
- Mode             : Route
- IP Mode          : PPPoE (IPv4)
- VLAN Mode        : Tag
- VLAN ID          : 100
- Port Binding     : Centang LAN1, LAN2, LAN3, LAN4, SSID1 (2.4G & 5G)
- NAT              : Enabled
4
Konfigurasi TR-069 ACS Template di OLT
TR-069 OMCI Config:
- ACS URL          : http://10.200.0.1:7547
- ACS Username     : admin
- ACS Password     : admin
- Periodic Inform  : Enable (300 Detik)
- WAN Interface    : WAN_TR069 (VLAN 20)
5
Hasil Otomatisasi di Lapangan

Teknisi di lapangan cukup pasang modem baru dari kardus → OLT mendeteksi serial number → konfigurasi ter-push dalam hitungan detik → Modem langsung muncul di GenieACS Pro dengan status Online!

Metode 2: Bulk Cloning dengan File Master XML

Sangat Cepat untuk Meja Gudang

Jika OLT Anda belum memiliki fitur push OMCI WAN, cara tercepat kedua adalah membuat 1 file konfigurasi master, lalu me-restore ke seluruh modem yang baru dibuka dari kardus. Waktu aktivasi hanya 20-30 detik per modem!

Master Fiberhome D2 (AN5506-02-B / HG6243C)

Sudah dikonfigurasi WAN 1 (VLAN 100 PPPoE), WAN 2 (VLAN 20 DHCP TR-069), ACS URL http://10.200.0.1:7547, WiFi Default BIONFIBER.

Master Fiberhome F3 (HG6045F3 / HG6821M Dual-Band)

Dual Band 2.4G & 5GHz, WAN 1 VLAN 100, WAN 2 VLAN 20 TR-069, ACS Inform 300s, Firewall Proteksi & Remote Access aktif.

1
Colok Kabel LAN Laptop ke Port LAN1 Modem Baru

Nyalakan modem, buka browser dan akses http://192.168.1.1.

2
Login dengan Akun Superadmin
Username: admin Password: %0@m?2#ZyKw atau Fh-n0c!
3
Buka Menu Device Management → Restore Configuration

Pilih menu Management → Device Management → Restore Configuration. Klik Browse, pilih file XML Master yang diunduh di atas, lalu klik Update Configuration.

4
Modem Reboot Otomatis → Selesai!

Dalam 30 detik modem restart. Begitu kabel optik dicolok di rumah pelanggan, modem langsung online di GenieACS dan teknisi tinggal menginput PPPoE user langsung lewat web billing Bionfiber!

Metode 3: One-Click Browser Console Script (Teknisi Lab)

Otomatisasi Form Web GUI

Untuk teknisi yang sedang membuka web GUI Fiberhome, Anda tidak perlu mengetik satu per satu kolom WAN & CWMP. Cukup tekan F12 (Developer Console), tempel script ini, lalu tekan Enter! 

// == BIONFIBER FIBERHOME ONE-CLICK TR-069 CONFIG INJECTOR ==
(function() {
    console.log("%c[BIONFIBER] Mengisi konfigurasi TR-069 Otomatis...", "color:#3b82f6; font-size:14px; font-weight:bold;");
    
    // 1. Auto-fill TR-069 CWMP Parameters
    const trUrl = document.querySelector('input[name*="acs_url"], input[id*="acs_url"], input[name*="ACSURL"]');
    const trUser = document.querySelector('input[name*="acs_user"], input[id*="acs_user"], input[name*="ACSUsername"]');
    const trPass = document.querySelector('input[name*="acs_pwd"], input[id*="acs_pwd"], input[name*="ACSPassword"]');
    const trInform = document.querySelector('input[name*="inform_interval"], input[id*="inform_interval"], input[name*="PeriodicInformInterval"]');
    const trEnable = document.querySelector('input[name*="tr069_enable"], input[id*="tr069_enable"], input[type="checkbox"][name*="enable"]');

    if (trUrl) trUrl.value = "http://10.200.0.1:7547";
    if (trUser) trUser.value = "admin";
    if (trPass) trPass.value = "admin";
    if (trInform) trInform.value = "300";
    if (trEnable) trEnable.checked = true;

    // 2. Auto-fill WAN Connection Form (Jika berada di tab Network WAN)
    const vlanIdInput = document.querySelector('input[name*="vlan_id"], input[id*="vlan_id"], input[name*="VLANID"]');
    const vlanEnable = document.querySelector('input[name*="vlan_enable"], input[id*="vlan_enable"]');
    if (vlanIdInput) vlanIdInput.value = "20";
    if (vlanEnable) vlanEnable.checked = true;

    alert("[BIONFIBER] Parameter TR-069 (VLAN 20 & ACS 10.200.0.1:7547) telah terisi otomatis! Silakan klik tombol 'Apply' / 'Save'.");
})();

Metode 4: Konfigurasi Web GUI Manual (Step-by-Step Lengkap)

Panduan Standar Operasional

Ikuti langkah-langkah di bawah ini jika ingin mengkonfigurasi manual satu per satu pada modem Fiberhome D2 atau F3:

Hubungkan laptop ke port LAN 1 menggunakan kabel UTP. Buka browser dan ketik alamat 192.168.1.1.

Masuk ke menu Network → Broadband Settings → Internet Connection:

  • Mode: Pilih Route
  • Service Type: Pilih INTERNET
  • Enable VLAN: Centang (Enable)
  • VLAN ID: Ketik 100 (Sesuai VLAN PPPoE MikroTik)
  • 802.1p Priority: 0
  • IP Protocol Version: IPv4
  • IPv4 Addressing Mode: Pilih PPPoE
  • Username & Password: Masukkan akun PPPoE pelanggan (Contoh: pelanggan01@bionfiber.net)
  • Port Binding: Centang semua port LAN (LAN1 - LAN4) dan SSID1 (2.4G & 5G) agar klien rumah mendapat akses internet.
  • Klik Apply / Save.

Masih di menu Internet Connection, klik tombol Add untuk membuat koneksi WAN baru:

  • Mode: Pilih Route
  • Service Type: Pilih TR069 (atau MANAGEMENT / TR069_VOICE)
  • Enable VLAN: Centang (Enable)
  • VLAN ID: Ketik 20 (Sesuai VLAN TR-069 MikroTik)
  • 802.1p Priority: 0
  • IP Protocol Version: IPv4
  • IPv4 Addressing Mode: Pilih DHCP (Modem akan otomatis meminta IP dari pool MikroTik 10.20.0.10 - 10.20.3.250)
  • Port Binding: JANGAN CENTANG PORT MANAPUN! (Koneksi ini murni digunakan internal modem untuk melapor ke GenieACS).
  • Klik Apply / Save.

Buka menu Administration (atau Application) → TR-069 / CWMP:

- Enable TR-069               : Centang (Enable)
- WAN Interface               : Pilih koneksi WAN 2 (Contoh: 2_TR069_DHCP_VID_20)
- ACS URL                     : http://10.200.0.1:7547
- ACS Username                : admin
- ACS Password                : admin
- Periodic Inform             : Centang (Enable)
- Periodic Inform Interval    : 300 (Detik / 5 Menit)
- Connection Request Username : admin
- Connection Request Password : admin
- Connection Request Port     : 7547 (Default)

Klik tombol Apply untuk menyimpan konfigurasi.

Cara Verifikasi Bahwa Modem Berhasil Terhubung
1. Cek di Web GUI Modem

Masuk ke menu Status → Device Information → WAN Connection. Pastikan interface VLAN 20 mendapatkan status Connected dan menerima IP 10.20.x.x.

2. Cek di Terminal MikroTik

Jalankan perintah ini di Winbox/Terminal RB5009 untuk melihat daftar sewa IP modem TR-069: 

/ip dhcp-server lease print where server=DHCP-TR069
3. Cek di GenieACS Pro

Buka menu GenieACS Pro di panel billing. Modem akan langsung muncul dengan Serial Number, Redaman Optik (dBm), SSID Wi-Fi, dan status Online hijau!

Tips & Solusi Troubleshooting
Modem Tidak Dapat IP di VLAN 20?

Periksa konfigurasi port uplink di OLT. Pastikan port uplink OLT di-set mode Hybrid atau Trunk yang mengizinkan (permit/pass) VLAN 20 selain VLAN 100 dan VLAN 10.

Modem Dapat IP tapi Tidak Muncul di GenieACS?

Pastikan rule NAT di MikroTik aktif: dst-address=10.200.0.0/24 src-address=10.20.0.0/22 action=masquerade. Coba ping dari MikroTik ke 10.200.0.1 untuk memastikan tunnel WireGuard ke VPS terhubung aktif.
